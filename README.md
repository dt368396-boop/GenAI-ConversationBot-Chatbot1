# GenAI ConversationBot - Multi-User AI Chatbot

A Multi-User AI Chatbot built in Python using Streamlit and Google Gemini API.
Multiple users can chat at the same time, and every user gets their own separate chat history.

## Features
- Multi-user support with separate chat history
- Real-time chat with Gemini AI
- Clean and simple Streamlit UI
- Chat history saved for each user

## Tech Used
- Python
- Streamlit
- Google Gemini API

## How to Run
pip install -r requirements.txt
streamlit run app.py
